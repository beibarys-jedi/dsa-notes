## Example 1
Sum of 3 numbers

```cpp
#include <iostream>
using namespace std;

int main() {
	int a;
	int b;
	int c;
	cin >> a >> b >> c;
	// "\n" can be replaced with endl as well
	cout << "The sum of these three numbers is " << a + b + c << "\n";
}
```

Run command

```shell
 clang++ -std=c++17 main.cpp -o main

 ./sum
 ```
